# ORBITAL — a cinematic space experience

An independent Hebrew/English space website created for Roy. This project lives only on the `orbital-space-20260906` branch. It does not change or deploy the existing website on main.

Art direction and scroll choreography informed by nateherkai/scroll-craft, especially its hero-depth guidance. Four custom Adobe Firefly conceptual images: astronaut, Earth, lunar horizon and Mars. These are artistic illustrations, not documentary mission photography. Native semantic HTML, CSS and JavaScript; no framework dependency.
